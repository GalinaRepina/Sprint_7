# Проект автоматизации тестирования API Скутерной компании

Проект автоматизированного тестирования REST API для сервиса заказа самокатов.

##  Технологии

- **Python 3.7+** - основной язык программирования
- **Pytest** - фреймворк для тестирования
- **Requests** - библиотека для HTTP-запросов
- **Allure** - система для генерации отчетов
- **Random** - генерация случайных данных

##  Структура проекта
Sprint_7/
├── tests/ # Директория с тестами
│ ├── test_courier_creation.py # Тесты создания курьера
│ ├── test_courier_deletion.py # Тесты удаления курьера
│ ├── test_courier_login.py # Тесты авторизации курьера
│ ├── test_order_acceptance.py # Тесты принятия заказов
│ ├── test_order_creation.py # Тесты создания заказов
│ └── test_order_list.py # Тесты получения списка заказов
├── .venv/ # Виртуальное окружение
├── requirements.txt # Зависимости проекта
└── README.md # Документация

# Запуск всех тестов
pytest tests/ -v

# Запуск тестов с сохранением результатов
pytest tests/ --alluredir=allure-results -v

# Генерация и открытие отчета
allure serve allure-results
